# fishtail-games.github.io

The Fishtail Apps developer website, served with GitHub Pages at https://fishtail-games.github.io.

- `app-ads.txt` authorizes Google AdMob (publisher `pub-1692002472157021`) to sell ads in our apps. AdMob reads it
  from the root of the developer website listed on each app's Google Play store listing, so this site's address goes in
  Play Console → Store settings → Website. If an app ever uses another ad network or AdMob account, add its line here.
- Privacy policies live in the separate [privacy-policy](https://github.com/Fishtail-Games/privacy-policy) repo,
  served at https://fishtail-games.github.io/privacy-policy/.
